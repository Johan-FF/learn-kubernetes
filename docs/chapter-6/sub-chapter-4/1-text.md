OpenShift(opens in a new tab) is an "enterprise" Kubernetes (Red Hat OpenShift Overview(opens in a new tab)). Claiming that you don't have Kubernetes because you have OpenShift would be equal to claiming "I don't have an engine. I have a car!"(opens in a new tab). For other options for production-ready Kubernetes see Rancher(opens in a new tab), which you might have seen before in this page https://github.com/rancher/k3d(opens in a new tab), and Anthos GKE(opens in a new tab), which might also sound familiar. They are all options when you're making the crucial decision between which Kubernetes distribution you want or would you like to use a managed service.
